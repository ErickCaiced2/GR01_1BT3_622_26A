## 📁 Archivos Creados/Modificados

### 1. ✅ **AdopcionController.java** (MODIFICADO)

**Nuevos Métodos:**

#### `descargarContratoPDF(@PathVariable Long id)`
```java
@GetMapping("/{id}/contrato/descargar")
public ResponseEntity<?> descargarContratoPDF(@PathVariable Long id)
```

**Características:**
- ✅ Endpoint REST GET: `/adopciones/{id}/contrato/descargar`
- ✅ Validación: Verifica si adopción existe (404 si no)
- ✅ Generación: Llama a `ContratoService.generarContratoPDF()`
- ✅ Headers HTTP correctos:
  - `Content-Type: application/pdf`
  - `Content-Disposition: attachment; filename=contrato_adopcion_N.pdf`
  - `Content-Length: {tamaño en bytes}`
- ✅ Logging detallado (info + debug)
- ✅ Manejo de excepciones: Retorna 500 con mensaje de error
- ✅ Validación de PDF vacío

#### `obtenerURLContratoDescarga(@PathVariable Long id)`
```java
@GetMapping("/{id}/contrato/url")
@ResponseBody
public ResponseEntity<?> obtenerURLContratoDescarga(@PathVariable Long id)
```

**Características:**
- ✅ Endpoint adicional para AJAX
- ✅ Retorna JSON con URL, nombre archivo y mensaje
- ✅ Útil para aplicaciones SPA o AJAX puro

```

└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  JavaScript: descargarContrato(adopcionId)                  │
│  - Desactiva botón                                          │
│  - Muestra spinner                                          │
│  - Realiza fetch GET a /adopciones/{id}/contrato/descargar │
└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  AdopcionController.descargarContratoPDF(@PathVariable id)  │
│  - Valida que adopción existe                              │
│  - Llamada a ContratoService.generarContratoPDF(id)        │
│  - Construye headers HTTP correctos                        │
│  - Retorna byte[] del PDF                                  │
└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  ContratoService.generarContratoPDF(Long adopcionId)        │
│  - Obtiene Adopcion de BD                                  │
│  - Mapea a ContratoDTO con AdopcionContratoMapper          │
│  - Renderiza HTML con Thymeleaf                            │
│  - Convierte a PDF con Flying Saucer (ITextRenderer)       │
│  - Retorna byte[]                                          │
└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  ResponseEntity con headers + byte[] PDF                   │
│  Content-Type: application/pdf                             │
│  Content-Disposition: attachment; filename=...             │
└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  JavaScript recibe blob del PDF                            │
│  - Crea URL temporal del blob                              │
│  - Crea <a> link con download attribute                    │
│  - Simula click para activar descarga                      │
│  - Libera memoria del blob URL                             │
│  - Restaura botón (desactiva spinner)                      │
└────────────────────────────┬────────────────────────────────┘
                             ↓
┌─────────────────────────────────────────────────────────────┐
│  PDF descargado en máquina del usuario                     │
│  Archivo: contrato_adopcion_{id}.pdf                       │
└─────────────────────────────────────────────────────────────┘
```
